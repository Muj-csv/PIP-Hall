# PIXEL PASS — Screen Specifications

## 1. Home

Purpose: immediately communicate the concept.

Structure:
- fictional retro-game sky/background
- PIXEL PASS wordmark
- compact navigation
- central member card
- neighboring cards partially visible
- swipe/drag hint
- search
- create-card CTA

## 2. Explore

Purpose: browse the full member collection.

Components:
- search
- filter controls
- grid/carousel toggle if useful
- member count
- member cards

## 3. Member Profile

Purpose: direct share destination.

Show:
- full card
- identity
- social links
- projects
- QR
- portfolio action

The public URL must work without login.

## 4. Register

Minimal fields:
- email
- password
- username

After signup, immediately guide the member to profile creation.

## 5. Create Card

Use a multi-step or well-organized single-page form.

Sections:
- identity
- links
- profile visibility
- project list
- card preview

The preview should update as the user edits fields.

## 6. Edit Card

Same editor as create, pre-populated.

Show moderation status clearly.

## 7. Admin

Visual style remains consistent with the retro world.

Sections:
- pending submissions
- published members
- featured members
- moderation action

Avoid making the admin area look like a completely different SaaS product.

## 8. Settings

- account info
- profile visibility
- public email toggle
- logout
- delete account
