# PIXENDO — Naming Direction

## Chosen Fictional Brand

**PIXENDO**

Use PIXENDO as the fictional retro-game universe/platform brand. Use **PIXEL PASS** for the member card system.

Example:

```text
PIXENDO
PIXEL PASS
Member Card Collection
```

## Why this works

The name deliberately has a retro-game-company sound without using the actual Nintendo name. It should be presented as an original fictional brand, not as a Nintendo replacement, official product, or affiliated service.

## Brand Rules

- Do not use the Nintendo wordmark.
- Do not reproduce Nintendo logos.
- Do not use official Nintendo UI assets.
- Do not use Mario character art or official sprites.
- Create original monochrome pixel-art assets.
- Keep the visual homage in the atmosphere, layout language, interaction patterns, and era-inspired pixel design.

## Interface Naming

Prefer fictional names such as:

- PIXENDO HOME
- PIXEL PASS
- PLAYER CARD
- PLAYER PROFILE
- PROJECT QUEST
- WORLD SELECT
- MEMBER WORLD
- CARD COLLECTION
- QUEST LOG

Avoid official Nintendo/Mario terms where they would make the product appear affiliated.
